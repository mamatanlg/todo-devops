## Project Overview
This project is a simple ToDo web application built with Next.js. It allows users to:
- add tasks
- mark tasks as complete
- delete tasks
- manage tasks in the browser

## Run the project locally
```bash
npm install
npm run dev
```

Then open:
```text
http://localhost:3000
```

The application is deployed using Vercel and connected to the GitHub repository.
